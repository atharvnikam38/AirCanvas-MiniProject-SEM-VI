

# ✨ AI-Powered Air Canvas ✨

An interactive Streamlit-based web application that transforms your webcam into an AI-powered virtual canvas. Designed for both general users and children, it supports hand-gesture drawing, shape recognition, tracing, math quizzes, Gemini AI-based OCR, and more!

---

## 📌 Description

This project offers two modes:
- **Normal Mode**: A feature-rich drawing experience with shape assist, disappearing effects, OCR using Google Gemini, and AI-powered problem solving.
- **Kids Mode**: An educational and fun drawing environment for children to trace letters, practice numbers, solve math quizzes, and get AI feedback via hand gestures.

Built with OpenCV, CVZone, Google Gemini, and Streamlit, this project blends computer vision, hand tracking, and generative AI to create a real-time, interactive whiteboard-like canvas in your browser.

---

## ✨ Features

- 🎨 Draw using hand gestures (index finger).
- ✂️ Erase using pinky gesture.
- 🔁 Undo & clear options.
- 🧠 OCR with Gemini AI.
- 🧩 Shape recognition and assist.
- 🧒 Kid-friendly letter/number tracing and math quizzes.
- ✋ Hand gesture guide.
- 💾 Save/load drawings.
- 🔍 Live OCR with Gemini analysis.
- 📏 Templates: Graph paper, music staff, text lines.

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/ai-air-canvas.git
cd ai-air-canvas

# Install dependencies
pip install -r requirements.txt
```

---

## 🚀 Usage

```bash
# Run the app
streamlit run main.py
```

> Make sure your webcam is connected and accessible.

You can switch between "Normal Mode" and "Kids Mode" via the Streamlit UI.
